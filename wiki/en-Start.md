# Getting Started

[⌂ Back to English guide](en-Home) · [Previous: Back to English guide](en-Home) · [Next: Startup & System Tray](en-Tray)

> A short walkthrough of setup, translation, and viewing game chat.

---

## Set up in five steps

1. **Launch War Thunder Chat Translator.** The app normally runs in the Windows system tray, so a Settings window may not appear immediately.
2. **Open Settings.** Expand the hidden icons area near the clock, right-click the app icon, and select **Settings**. You can also double-click the icon.
3. **Choose your chat translation preferences.** Open **Translation Settings**, then pick a translation service and the **target language** you want to read.
4. **Run a quick test.** Select **Test Translation**, enter a short phrase, and check that a translation appears.
5. **Open the game and choose a view.** Start War Thunder. Use **Dashboard** from the tray to read chat in a browser, or **Show/Hide Overlay** to display it over the game.

![Browser chat Dashboard](images/01-dashboard.jpg)

> 💡 An empty chat view does not necessarily indicate a problem. The app may simply be waiting for new messages from the game.

## Three different language settings

| Setting | What it changes | Where to find it |
| --- | --- | --- |
| **App language** | Menus, Settings, and prompts | **Appearance → Interface Settings** |
| **Chat target language** | The language used for translated game chat | **Translation Settings** |
| **Voice shortcut target language** | The output language assigned to each voice shortcut | **Voice Translation** |

These choices are independent. For example, you can use the English interface while translating game chat into Chinese.

## Choose how you want to use the app

- **In-game reading:** use the [overlay](en-Overlay), without keeping a browser open.
- **Second-monitor setup:** open the [Dashboard](en-Dashboard) and move the browser to your other display.
- **Translate what you say:** configure [voice translation](en-Voice) and paste the result into chat.
- **Want less screen reading during a match?** Enable [Chat Voice Playback](en-Chat-TTS) with Microsoft system voices or the bundled Kokoro model.
- **Streaming and want cleaner spoken audio?** Enable only the TTS side of [Content Filtering](en-Content-Filter); the private Dashboard can still show the complete translation.
- **Open a view automatically:** change the options under [Runtime Settings](en-Preferences).

## Are my settings saved?

Most selections are saved when you make them. When editing an AI model, choose **Save**; when adjusting overlay coordinates or size, choose **Apply**. Closing the Settings window usually leaves the app running. To quit entirely, select **Exit** in the tray menu.
