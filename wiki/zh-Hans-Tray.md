# 启动与系统托盘

[⌂ 返回简体中文目录](zh-Hans-Home) · [上一页: 快速开始](zh-Hans-Start) · [下一页: 聊天翻译](zh-Hans-Translation)

> 认识托盘菜单、关闭窗口和真正退出的区别。

---

## 程序启动后在哪里？

应用通常在 **Windows 系统托盘**运行。请查看任务栏右下角；如果没看到图标，点击隐藏图标箭头展开列表。正常启动时可能出现一条“程序已启动，请通过托盘访问”的系统通知。即使通知被 Windows 关闭，也不影响从托盘进入程序。

## 托盘菜单一览

| 菜单 | 可以做什么 |
| --- | --- |
| **显示/隐藏悬浮窗** | 第一次点击显示，再次点击隐藏 |
| **面板** | 在默认浏览器中打开聊天 Dashboard |
| **设置** | 打开或返回设置窗口 |
| **退出** | 完全结束应用运行 |

双击托盘图标也可以打开设置。**关闭设置窗口右上角的 × 与“退出”不是同一件事**：关闭窗口后，后台翻译通常仍会继续。

## 隐藏悬浮窗后怎么找回来？

你可以在悬浮窗齿轮菜单中选择 **隐藏悬浮窗**，也可以在它显示时再次点击托盘的 **显示/隐藏悬浮窗**。两种操作效果相同，都不会清空位置和外观设置。恢复时再点击一次托盘菜单即可。

## 图标总是藏在折叠区域？

Windows 决定哪些托盘图标固定显示。可以在 **Windows 设置 → 个性化 → 任务栏**中调整对应通知区域图标的显示方式，也可以尝试把图标从折叠列表拖到可见位置。应用本身无法强制永久固定图标。

## 重复打开程序怎么办？

如果应用已经运行，再次启动可能提示它正在运行。此时使用现有的托盘图标即可，无须重复启动。要重新打开程序，请先选择 **退出**，再正常启动。

> ➜ 想要启动后自动打开 Dashboard 或悬浮窗？见[运行与网络设置](zh-Hans-Preferences)。
