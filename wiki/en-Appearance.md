# Appearance & Language

> Change app language, theme, chat fonts, colors, and overlay placement.

---

![Chat style settings](images/07-chat-styles.jpg)

## Change the app language

Open **Appearance → Interface Settings** and choose **Simplified Chinese, Traditional Chinese, or English**. Once you choose a language manually, that preference is kept on future launches; Windows language changes will not override it.

Before you make a manual choice, the app selects from those three languages based on Windows display-language preferences. If your system language is not supported, the app uses English and shows a one-time explanation. **The app language does not change your chat translation target.**

## Choose a light or dark theme

On the same page, select **Light, Dark, or Follow System**. Choose Follow System to match Windows. If a few labels do not refresh immediately, close and reopen the Settings window.

There is also an advanced background appearance option. For normal customization, start with the theme and chat style controls; you do not need to change advanced options.

## Customize chat text

Open **Appearance → Chat Styles**:

- **Font:** choose a typeface that is easy to read.
- **Text size and weight:** adjust them for your screen and viewing distance.
- **Friendly, enemy, and system message colors:** set them separately so message types are easy to distinguish.

The Dashboard and overlay use the corresponding chat text styles. Available fonts may vary between computers.

## Set up the overlay layout

Under **Appearance → Overlay**, choose the display and adjust position or size. If you lose track of the window, use **Center on Selected Display**. For hands-on movement and resizing, see the [Overlay Guide](en-Overlay).
