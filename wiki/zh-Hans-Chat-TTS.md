# 聊天语音播报

[⌂ 返回简体中文目录](zh-Hans-Home) · [上一页: 语音翻译](zh-Hans-Voice) · [下一页: 不文明内容过滤](zh-Hans-Content-Filter)

> 将已经翻译完成的聊天消息直接播报出来，减少战斗中查看文字的频率。

![聊天语音播报设置](images/09-chat-tts.png)

---

## 声音来源

可以在三种声音来源之间切换：

- **Microsoft SpeechSynthesizer**：使用 Windows 已安装的系统音色，本地合成，资源占用较低。
- **本地模型（Kokoro v1.1）**：使用随应用分发的 Kokoro v1.1 INT8 模型，通过 sherpa-onnx 在本机运行，提供多种中英文音色。
- **GPT-SoVITS 角色语音**：连接用户已经启动的 GPT-SoVITS API 服务，可为不同角色保存模型、参考音频和参考文本。应用本身不会安装或启动 GPT-SoVITS。

Kokoro 是内置模型，不需要在应用中下载、导入或删除。若模型文件缺失，页面会在“模型状态”中提示，音色选择也会自动禁用。

## 播报设置与音频输出设备

可以调整音色、语速和音量，使用“试听”确认实际播报效果。

在“音频输出设备”中，可选择**系统默认**（Windows 默认输出），也可以指定扬声器、耳机或虚拟声卡。插拔设备后点击**刷新**重新获取列表。如果已保存的设备显示为“当前不可用”，请重新连接设备，或改选其他可用设备（包括系统默认输出）。

## Kokoro 模型与线程数

使用“本地模型（Kokoro v1.1）”时，可在“模型状态”确认内置模型是否可用。“性能占用”可设置 Kokoro 线程数，范围为 **1～16**：线程越多，生成语音通常越快，但 CPU 占用也可能更高，建议先使用默认值。若内置模型缺失，应检查或恢复完整的应用安装文件，而不是在页面内寻找模型下载功能。

## GPT-SoVITS 连接与角色配置

1. 自行启动 GPT-SoVITS API 服务，在“服务地址”中填写 API 地址（默认 `http://127.0.0.1:9880`），然后在“服务状态”点击**检查**，确认服务能够访问。
2. 进入“角色配置”，点击**添加角色**。角色名称和参考音频路径是必填项。GPT（`.ckpt`）及 SoVITS（`.pth`）模型权重路径可选；不填写时使用 API 服务当前加载的模型。
3. 按需填写参考文本、参考文本语言和输出文本语言，保存后对需要播报的角色点击**使用**；已保存的角色还可以**编辑**或**删除**。
4. 使用“试听”验证所选角色。合成语音时，GPT-SoVITS 服务必须处于运行状态，填写的文件路径也必须能被该 API 服务访问。

应用只负责连接 GPT-SoVITS，不会自动安装或启动该服务。

## 消息队列

战斗中的聊天可能连续出现，因此语音播报使用等待队列：

- **最大等待消息数**决定最多保留多少条尚未播报的消息。
- **消息等待过久**可以设为永不过期，或按秒数丢弃已经失去时效的旧消息。
- 队列满时优先舍弃较旧的等待消息，避免几秒前的战况一直排队播放。

## 哪些消息会播报？

友军、敌军和系统消息可以分别开关。若同时启用了[不文明内容过滤](zh-Hans-Content-Filter)中的 TTS 过滤，语音播报会按照那里设置的策略处理敏感内容。

> 💡 屏幕显示过滤与 TTS 过滤彼此独立，所以可以让 Dashboard 保留完整翻译，同时只过滤会被直播录入的语音。
