## 启动与托盘

| 遇到的情况 | 可以这样处理 |
| --- | --- |
| 启动后没有设置窗口 | 展开任务栏右下角隐藏图标区域，右键图标选择 **设置** |
| 关闭设置后程序还在运行 | 这是正常的后台模式；从托盘选择 **退出** 才会完全关闭 |
| 提示应用已经运行 | 使用当前托盘图标，不需要再启动一个 |
| 没看到启动通知 | 检查 Windows 通知设置；只要托盘可以操作，不影响使用 |
| 图标一直被折叠 | 到 Windows 任务栏设置调整图标的显示方式 |

## 翻译与 Dashboard

| 遇到的情况 | 可以这样处理 |
| --- | --- |
| 点击 **面板** 后打不开网页 | 确认应用仍在运行，稍后重试或完全退出后重新启动；不要依赖旧书签 |
| 页面显示“等待聊天” | 确认 War Thunder 正在运行，并等待游戏里出现新聊天 |
| 只看到原文 | 检查 Dashboard 的 **消息显示**，选择包含译文的模式 |
| 翻译结果迟迟不出现 | 在设置中点击 **测试翻译功能**，检查所选服务和网络 |
| AI 模型无法使用 | 在模型列表中 **测试**、**使用**，并在翻译设置中选择 AI 翻译 |

## 悬浮窗与语音翻译

| 遇到的情况 | 可以这样处理 |
| --- | --- |
| 悬浮窗消失 | 托盘点击 **显示/隐藏悬浮窗**；仍看不到就到布局设置中将它居中 |
| 游戏中无法点击悬浮窗齿轮 | **Alt + Tab** 暂时切出游戏后再调整 |
| 隐藏后设置丢失了？ | 正常隐藏不会清除窗口设置，重新显示即可 |
| 开启语音翻译后开关自动关闭 | 检查页面提示、Windows 麦克风权限与选定设备 |
| 快捷键无效 | 检查是否已启用，或换用不与其他软件冲突的按键 |
| 结束录音后没有译文 | 确认使用**同一个快捷键**结束录音，并先测试普通翻译功能 |

## 界面语言与显示

- **不支持的系统语言显示英文**：这是正常回退。可前往 **外观 → 界面设置**手动选择中文或英文。
- **手动选择的语言会被覆盖吗？** 不会，应用会优先保留你的手动选择。
- **切换语言后有些文字没有变化**：重新打开设置窗口；仍未变化可完全退出后重启。
- **网页主题与悬浮窗不一致**：两个视图有各自的显示选项，请分别调整。

## 仍然解决不了怎么办？

建议依次完成：**检查托盘 → 测试翻译 → 检查 Dashboard → 检查悬浮窗或语音功能**。向项目反馈时描述操作步骤、看到的提示、Windows 和应用版本；请勿公开服务密钥或私密聊天内容。
