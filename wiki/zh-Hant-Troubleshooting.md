# 常見問題

> 依照遇到的情況快速尋找解決方法。

---

## 啟動與系統匣

| 遇到的情況 | 建議處理方式 |
| --- | --- |
| 啟動後沒有設定視窗 | 展開工作列右下角的隱藏圖示，選擇 **設定** |
| 關閉設定後程式仍在執行 | 這是正常的背景模式；從系統匣選擇 **退出** 才會完全結束 |
| 顯示「程式已在執行」 | 使用現有的系統匣圖示即可 |
| 沒看到啟動通知 | 檢查 Windows 通知設定；只要系統匣仍可操作，就能正常使用 |
| 系統匣圖示一直被收起 | 在 Windows 工作列設定中調整顯示方式 |

## 翻譯與 Dashboard

| 遇到的情況 | 建議處理方式 |
| --- | --- |
| 按下 **面板** 卻無法開啟網頁 | 確認程式仍在執行，稍後重試或完全退出後重新開啟；不要依賴舊書籤 |
| 頁面一直顯示等待聊天 | 確認 War Thunder 已啟動，並等待遊戲出現新的聊天訊息 |
| 只看到原文 | 檢查 Dashboard 的 **訊息顯示**，選擇包含譯文的模式 |
| 譯文沒有出現 | 在設定中執行 **測試翻譯功能**，確認服務和網路狀態 |
| AI 模型無法使用 | 在模型清單依序 **測試**、**使用**，再於翻譯設定選擇 AI 翻譯 |

## 懸浮視窗與語音翻譯

| 遇到的情況 | 建議處理方式 |
| --- | --- |
| 懸浮視窗不見了 | 從系統匣重新顯示；仍找不到時到配置設定中將視窗置中 |
| 遊戲中點不到齒輪 | 先按 **Alt + Tab** 切出遊戲再操作 |
| 隱藏後擔心設定消失 | 正常隱藏不會清除設定，再次顯示即可 |
| 開啟語音功能後開關自行關閉 | 查看頁面提示、Windows 麥克風權限與錄音裝置 |
| 快捷鍵無效 | 確認功能已啟用，或改用不與其他軟體衝突的快捷鍵 |
| 錄音結束後沒有譯文 | 使用**同一組快捷鍵**結束錄音，並先測試一般翻譯 |

## 聊天語音播報與內容過濾

| 遇到的情況 | 建議處理方式 |
| --- | --- |
| 已開啟 TTS 但沒有聲音 | 檢查允許播報的訊息類型、音量與「音訊輸出裝置」，先使用「試聽」確認，並檢查 Windows 是否將裝置設為靜音。 |
| 找不到輸出裝置或顯示無法使用 | 重新連接耳機或喇叭，在裝置選擇旁按下**重新整理**，改選可用裝置或**系統預設**。 |
| Kokoro 音色無法載入或模型遺失 | 查看「模型狀態」，並確認安裝內容完整；若語音合成初始化失敗，可先將執行緒數恢復預設值再試聽。 |
| GPT-SoVITS 無法連線 | 確認已自行啟動 GPT-SoVITS API 服務，核對 API 位址與連接埠（預設 `http://127.0.0.1:9880`）、網路存取情況，再按一次「檢查」。 |
| GPT-SoVITS 角色無法儲存或播報 | 角色名稱與參考音訊路徑都必須填寫；確認檔案路徑可由 API 服務存取，為要使用的角色選擇「使用」，再透過「試聽」檢查。 |
| 新增黑名單詞條後仍未過濾 | 確認已開啟需要的「過濾畫面顯示」或「過濾語音播報」開關；檢查整體過濾程度、詞條嚴重程度、匹配方式，以及是否有優先的白名單項目。 |
| 匯入後舊規則仍存在 | 這是正常行為：TXT/JSON 匯入採**合併**方式，不會替換整個自訂詞庫。舊詞條須手動移除。TXT 預設每行一個黑名單詞條、嚴重程度 2、自動匹配；JSON 可還原黑白名單。 |

## 介面語言與外觀

- **不支援的系統語言使用英文**：這是正常的預設方式；可到 **外觀 → 介面設定** 手動選擇語言。
- **手動選擇會被系統語言覆蓋嗎？** 不會，程式會優先保留手動選擇。
- **切換語言後部分文字沒更新**：關閉並重新開啟設定視窗；如有需要，可完全退出後再啟動。
- **Dashboard 與懸浮視窗外觀不同**：兩者各有顯示選項，請分別調整。

## 還是無法解決？

建議依序檢查：**系統匣 → 翻譯測試 → Dashboard → 懸浮視窗或語音功能**。回報問題時，請說明操作步驟、畫面提示、Windows 與應用程式版本，並避免公開密鑰或私人聊天內容。
