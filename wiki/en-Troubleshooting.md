## Startup and system tray

| Problem | Try this |
| --- | --- |
| No Settings window appears on launch | Expand the hidden tray icons near the clock and choose **Settings** |
| The app keeps running after Settings closes | This is expected; choose **Exit** from the tray to quit completely |
| A message says the app is already running | Use the existing tray icon |
| No startup notification appears | Check Windows notifications; the tray icon is the main way to access the app |
| The tray icon keeps being hidden | Adjust notification-area icons in Windows taskbar settings |

## Translation and Dashboard

| Problem | Try this |
| --- | --- |
| **Dashboard** does not open | Confirm the app is running, try again from the tray, or restart the app; avoid old bookmarks |
| The Dashboard is waiting for chat | Start War Thunder and wait for new in-game chat messages |
| Only original text is shown | Switch **Message Display** to a mode that includes translations |
| Translations do not arrive | Run **Test Translation**, then check the selected provider and internet connection |
| AI translation is unavailable | **Test** and **Use** the model, then select AI Translation under Translation Settings |

## Overlay and voice translation

| Problem | Try this |
| --- | --- |
| The overlay has disappeared | Show it from the tray; if needed, center it on the selected monitor in Appearance |
| You cannot click the overlay gear in-game | Switch away from the game with **Alt + Tab** before interacting |
| You are worried hiding reset the layout | Normal hiding preserves your overlay preferences; simply show it again |
| The voice toggle turns itself off | Check the on-screen warning, microphone selection, and Windows permissions |
| A voice shortcut does not work | Verify the feature is on, or change conflicting shortcuts |
| No translation follows recording | Stop with **the same shortcut** used to start; also test the translation service |

## App language and appearance

- **My unsupported system language uses English:** this is the intended fallback. Pick a language manually under **Appearance → Interface Settings** if preferred.
- **Will a manual language choice be replaced?** No. The app keeps your manual selection.
- **Some labels did not update:** reopen Settings, or exit and relaunch the app.
- **The browser and overlay look different:** their display preferences can be adjusted separately.

## Still need help?

Check in this order: **tray → translation test → Dashboard → overlay or voice translation**. When reporting an issue, include steps to reproduce it, any on-screen messages, and your Windows and app versions. Do not post keys or private chat text.
