# 语音翻译

> 设置麦克风、快捷键、录音步骤和提示音。

---

![语音翻译设置](images/05-voice-translation.jpg)

## 第一次启用

1. 打开左侧 **语音翻译**。
2. 在**录音设备**中选择系统默认麦克风或指定设备；找不到设备时点击 **刷新**。
3. 说几句话，观察输入音量是否有反应。如页面提示麦克风不可用，请按提示检查 Windows 麦克风权限。
4. 开启 **启用快捷语音翻译**，检查快捷键与对应的目标语言。

## 一次完整的语音翻译

1. 按一下对应目标语言的快捷键，**开始录音**。
2. 说出想表达的话。
3. **再次按同一个快捷键**，结束录音。
4. 翻译完成后，结果会复制到剪贴板；切到游戏聊天框，**手动粘贴并发送**。

录音过程中，按其他语言的快捷键不会切换当前录音，请先用原来的快捷键结束。

## 默认快捷键

| 快捷键 | 翻译成 |
| --- | --- |
| `Ctrl + Alt + 1` | 英语 |
| `Ctrl + Alt + 2` | 俄语 |
| `Ctrl + Alt + 3` | 德语 |
| `Ctrl + Alt + 4` | 日语 |
| `Ctrl + Alt + 5` | 韩语 |

如果与游戏或其他软件的按键冲突，可在列表里重新录入组合键。每个快捷键还可以单独修改目标语言，也可以新增或删除快捷键。

## 提示音和录音体验

录音开始、录音结束、翻译成功、翻译失败都有单独的提示音选项。你可以选择系统提示音、语音提示或自己的音频文件，并预览效果。还可以调整播放音量和录音开始时机。

## 出现问题时先做什么？

- **开关自动关闭**：查看页面上的权限或设备提示，并重新选择麦克风。
- **按键没有反应**：检查功能是否开启，以及快捷键是否与其他程序冲突。
- **录音正常但没有译文**：返回[翻译设置](zh-Hans-Translation)做一次翻译测试。
- **成功却没有发到游戏**：程序只会复制译文，不会自动替你发送聊天消息。

> 💡 语音快捷键的目标语言与游戏聊天的目标语言互不影响。
