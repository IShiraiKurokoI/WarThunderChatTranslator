# 外觀與介面語言

> 介面語言、明暗主題、聊天字型與懸浮視窗配置。

---

![聊天樣式設定](images/07-chat-styles.jpg)

## 變更應用程式語言

開啟 **外觀 → 介面設定**，選擇 **簡體中文、繁體中文或 English**。手動選擇後，程式會記住你的偏好；下次啟動時不會因為 Windows 顯示語言不同而覆蓋。

如果從未手動選擇，程式會依 Windows 顯示語言，自動選擇這三種介面語言之一。遇到尚未支援的系統語言時，會採用英文並顯示一次提示。**介面語言不會改變聊天翻譯的目標語言。**

## 明亮、深色與跟隨系統

在同一頁選擇 **淺色、深色或跟隨系統**。想與 Windows 主題保持一致時，使用「跟隨系統」即可。如果個別視窗的文字沒有立即更新，可以關閉並重新開啟設定視窗。

頁面也提供背景樣式的進階調整。如果只是想改善閱讀體驗，建議先使用主題及聊天樣式，無須修改進階項目。

## 自訂聊天文字

前往 **外觀 → 聊天樣式**：

- **字型**：挑選閱讀舒適的字型。
- **字體大小與粗細**：依照螢幕尺寸與觀看距離調整。
- **友軍、敵軍、系統訊息顏色**：分別設定，幫助快速分辨訊息來源。

Dashboard 和懸浮視窗會使用相應的聊天文字樣式。不同電腦可用的字型可能不同。

## 調整懸浮視窗配置

在 **外觀 → 懸浮視窗** 選擇螢幕，並修改位置與大小。若視窗不見了，使用 **在所選顯示器置中**。操作方式請參閱[遊戲懸浮視窗](zh-Hant-Overlay)。
