# Voice Translation

> Set up microphone shortcuts, recordings, and feedback sounds.

---

![Voice Translation settings](images/05-voice-translation.jpg)

## Enable voice translation for the first time

1. Open **Voice Translation** from the left navigation.
2. Under **Recording Device**, choose the default microphone or a specific device. Select **Refresh** if yours is not listed.
3. Speak briefly and check for activity on the microphone level indicator. If there is a warning, follow the prompt to check Windows microphone permissions.
4. Turn on **Enable Quick Voice Translation**, then review the assigned shortcuts and target languages.

## Translate something you say

1. Press the shortcut assigned to the language you want: this **starts recording**.
2. Speak your message.
3. **Press the same shortcut again** to stop recording.
4. When translation succeeds, the result is copied to your clipboard. Switch to the in-game chat box, then **paste and send it yourself**.

Pressing a different language shortcut during a recording does not switch it. Finish the current recording with the original shortcut.

## Default shortcuts

| Shortcut | Translates into |
| --- | --- |
| `Ctrl + Alt + 1` | English |
| `Ctrl + Alt + 2` | Russian |
| `Ctrl + Alt + 3` | German |
| `Ctrl + Alt + 4` | Japanese |
| `Ctrl + Alt + 5` | Korean |

You can record a different key combination if it conflicts with the game or other apps. Each shortcut has its own target language; shortcuts can also be added and removed.

## Sound feedback

Recording start, recording end, translation success, and translation failure each have their own sound settings. Choose a system sound, a spoken cue, or your own audio file, and preview it. You can also adjust volume and when recording begins relative to the sound.

## Common voice issues

- **The toggle turns itself off:** read the warning and check your microphone device and Windows permissions.
- **The shortcut does nothing:** make sure the feature is enabled and try a combination that is not used elsewhere.
- **Recording works but nothing is translated:** try [Test Translation](en-Translation) to check your current translation service.
- **Nothing was sent in-game:** the app copies text, but does not send chat automatically.

> 💡 Voice shortcut languages are independent of the target language used for incoming game chat.
