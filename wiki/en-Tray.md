# Startup & System Tray

[⌂ Back to English guide](en-Home) · [Previous: Getting Started](en-Start) · [Next: Chat Translation](en-Translation)

> Where to find the app and what the tray menu commands do.

---

## Where does the app go after launch?

War Thunder Chat Translator normally runs in the **Windows system tray** near the clock. If you cannot see its icon, expand the hidden icons area. Windows may show a startup notification saying the app is ready in the tray; disabling notifications does not prevent you from accessing the app.

## Tray menu reference

| Menu item | What it does |
| --- | --- |
| **Show/Hide Overlay** | Shows the overlay when hidden, hides it when visible |
| **Dashboard** | Opens the chat Dashboard in your default browser |
| **Settings** | Opens or brings back the Settings window |
| **Exit** | Quits the app completely |

Double-clicking the tray icon also opens Settings. **Closing the Settings window is not the same as Exit:** translation can continue in the background after the window closes.

## How do I restore a hidden overlay?

You can choose **Hide Overlay** from the overlay's gear menu or select **Show/Hide Overlay** again while it is visible. Both actions hide the same window without clearing its layout or appearance preferences. Choose the tray option again to restore it.

## Can the tray icon stay visible?

Windows controls which icons appear directly in the notification area. Look under **Windows Settings → Personalization → Taskbar** for the relevant tray icon controls, or try dragging the app icon out of the hidden area. The app cannot permanently force Windows to pin it.

## I launched the app twice

If it is already running, launching it again may show an “already running” message. Continue using the existing tray icon. To restart, first choose **Exit**, then launch the app normally.

> ➜ To open the Dashboard or overlay automatically at startup, see [Runtime and Network Settings](en-Preferences).
