## 启动行为

在 **运行设置** 中，可以选择是否在程序启动时自动打开 **悬浮窗**、是否自动打开 **Dashboard**。如果希望程序安静地在后台运行，将对应选项关闭即可，需要时再从托盘打开。

## 局域网访问与 Windows 防火墙

WarThunderChatTranslator 的本地 HTTP 服务会监听局域网接口，因此**监听本身不要求管理员权限**。是否能从手机、平板或另一台电脑访问 Dashboard，主要取决于 Windows 防火墙是否存在有效的允许规则。

如果你**只在这台电脑上使用 Dashboard**，不需要配置防火墙规则，也无需因为这里显示“尚未配置”而进行任何操作。

如果需要让局域网内其他设备访问 Dashboard：

1. 打开 **运行设置 → 局域网访问**。
2. 在 **Windows 防火墙**卡片中查看当前状态。
3. 点击 **允许局域网访问**。普通权限运行时，程序会先说明用途，再请求一次 Windows UAC 管理员确认。
4. 配置完成后，运行设置会优先选择当前有流量并具备外部网络访问的网卡，同时显示 Dashboard 地址与二维码；手机或平板可直接扫码访问。
5. 如需限制其他局域网设备访问，可开启 **访问认证**。认证默认关闭；开启后使用每次程序启动随机生成的会话令牌。本机访问始终免认证。

应用会优先判断 Windows 防火墙是否**实际上已经允许当前程序访问当前 Dashboard 端口**。如果你已经在 Windows 的“允许访问”提示中放行，或管理员/组策略已经创建了足够的入站允许规则，应用会直接认可该规则，不会要求重复“修复”。只有在确实没有可用允许规则时，才会提示创建或修复。

应用自己创建的规则会限制为：**当前 WarThunderChatTranslator 程序路径 + 当前 TCP 端口 + LocalSubnet + Private/Domain 网络配置**，而不是简单开放一个端口给所有程序。

### 防火墙状态说明

| 状态 | 含义与处理 |
| --- | --- |
| **已允许局域网访问** | Windows 当前存在能覆盖本应用、当前 Dashboard TCP 端口和当前网络配置的有效入站允许规则。它可以是应用创建的规则，也可以是 Windows“允许访问”提示或管理员创建的规则；只要已经够用，就不会要求修复。 |
| **尚未配置防火墙规则** | 没有匹配规则。只在本机使用时可以保持不配置；需要其他设备访问时再点击允许。 |
| **防火墙规则需要更新** | 已发现 WarThunderChatTranslator 规则，但程序路径、端口或规则内容与当前状态不一致。点击 **修复防火墙规则**。 |
| **本地 HTTP 服务未运行** | Dashboard 服务当前未成功启动，先重启应用或检查相关错误。 |
| **无法检查规则** | Windows 防火墙状态读取失败，可稍后重试或查看日志。 |

### Microsoft Store 更新后的规则

Microsoft Store 更新应用后，安装目录中的版本路径可能变化。旧防火墙规则即使名称仍然存在，也可能仍指向旧版本的 EXE，因此不能继续视为有效规则。

程序会先按**实际有效性**检查当前 EXE、TCP 端口、方向、Allow 状态和当前网络配置。Windows 自动生成的更宽泛应用规则（例如允许当前程序的 Any protocol / Any port）只要确实覆盖当前 Dashboard 连接，也会被视为有效。对于应用自己管理的规则，仍会记录旧路径以便在真正失效时提示修复：

- 普通权限启动时，如果发现旧规则，会发送提示但不会在启动时突然弹出 UAC；点击该通知会直接打开主窗口并跳转到 **运行设置 → 局域网访问**，再由你决定是否修复。
- 已经以管理员权限运行时，如果用户没有明确关闭自动管理，程序会自动创建或修复规则。
- 已有正确规则时，普通权限运行同样可以正常接受局域网连接，不需要一直以管理员身份运行。

### 移除规则

已经配置规则后，可以点击 **移除防火墙规则**。普通权限运行时，删除规则同样需要一次 UAC 管理员确认。

主动移除后，应用会记住这个选择，不会在下一次管理员启动时自动重新创建。以后如果再次点击 **允许局域网访问**，则恢复规则并重新启用自动维护。

> 局域网访问规则当前仅针对 **Private / Domain** 网络配置和 **LocalSubnet**。如果 Windows 把当前网络识别为 Public，其他设备可能仍无法访问。

## 消息更新频率

**游戏聊天更新间隔**和 **Dashboard 更新间隔**分别控制新消息的检查频率。通常保留默认值即可；希望显示更及时可以适当缩短，遇到响应慢或占用较高时可以适当增加。

## 战斗结束后如何处理聊天历史？

| 选项 | 适合谁 |
| --- | --- |
| **不清理** | 希望继续看到之前的聊天 |
| **逻辑清理** | 希望新一场战斗的显示更清爽，推荐日常使用 |
| **物理清理** | 希望更彻底地删除旧聊天；删除后不能从界面恢复 |

还可以设置聊天缓存容量。容量不是永久聊天归档；如果特别在意保留记录，请避免使用会删除旧内容的选项。

## 网络与代理设置

进入 **代理设置**，根据自己的网络情况选择：

- **不使用代理**：普通网络环境可先使用此项。
- **使用系统代理**：希望应用跟随 Windows 的代理设置时选择。
- **自定义代理**：只有已经有可用代理服务及其连接信息时才选择，按页面提示填写。

更改后可以回到 **翻译设置 → 测试翻译功能**确认是否正常。代理填写不正确时，翻译可能无法连接。

## 两个常见使用方案

**游戏内精简模式：** 开启“启动时打开悬浮窗”，关闭“启动时打开 Dashboard”。

**第二屏 / 局域网设备模式：** 开启 Dashboard，并在需要从其他设备访问时配置 Windows 防火墙规则；如果 Dashboard 只在本机浏览器使用，不需要配置局域网规则。
