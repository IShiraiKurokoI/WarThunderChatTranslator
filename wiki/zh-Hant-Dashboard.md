# 瀏覽器 Dashboard

> 在瀏覽器閱讀遊戲聊天並切換顯示方式。

---

![Dashboard 聊天面板](images/01-dashboard.jpg)

## 如何開啟？

在 Windows 系統匣對應用程式圖示按滑鼠右鍵，選擇 **面板**。程式會以預設瀏覽器開啟 Dashboard。建議每次都透過此選單進入，不要將某個暫時的瀏覽器位址設為固定書籤。

如果希望程式啟動時自動開啟瀏覽器，可以在 **執行設定** 中啟用對應選項。

## 頁面上有哪些顯示選項？

| 選項 | 效果 |
| --- | --- |
| **訊息顯示** | 只看譯文、只看原文，或同時顯示兩者 |
| **顯示來源語言代碼** | 選擇是否顯示辨識到的原文語言標記 |
| **深夜模式** | 切換較明亮或較暗的瀏覽外觀 |
| **顯示聊天氣泡背景** | 顯示或隱藏每則訊息的背景 |
| **遊戲執行狀態** | 瞭解程式是否偵測到正在執行的遊戲 |

友軍、敵軍及系統訊息可以使用不同的字體與顏色；相關選項請見[外觀與文字](zh-Hant-Appearance)。

## 從其他裝置開啟 Dashboard

如果要從同一區域網路中的手機、平板或另一台電腦開啟 Dashboard，請先到 **執行設定 → 區域網路存取**檢查 Windows 防火牆狀態。只有跨裝置存取才需要這條規則；若 Dashboard 只在本機瀏覽器使用，則不需要設定。

設定後，請使用這台電腦的**區域網路 IPv4 位址 + Dashboard 目前連接埠**存取。不要在其他裝置使用 `127.0.0.1` 或 `0.0.0.0`。

執行設定會優先選擇**目前有流量且可以連線到外部網路的網路介面**，並直接產生 QR Code。手機或平板與電腦位於同一區域網路時，可以掃描後開啟 Dashboard。

區域網路驗證為可選功能，預設關閉。啟用後，其他裝置需要本次程式啟動時隨機產生的工作階段令牌；**本機存取永遠免驗證**，包含使用本機區域網路 IP 開啟 Dashboard。

詳細說明請見[執行與網路設定](zh-Hant-Preferences)。

## 為什麼沒有出現新訊息？

如果遊戲尚未啟動、沒有新聊天，或翻譯仍在進行，Dashboard 可能顯示等待內容。請先確認遊戲內確實出現了新聊天，再檢查[翻譯設定](zh-Hant-Translation)。

## 換一個瀏覽器，外觀怎麼不同？

部分網頁顯示偏好由瀏覽器分別記住，換用其他瀏覽器或清除瀏覽資料後，可能需要重新選擇。Dashboard 與[懸浮視窗](zh-Hant-Overlay)的顯示選項可以分開設定。
