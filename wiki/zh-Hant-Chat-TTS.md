# 聊天語音播報

> 將已完成翻譯的聊天訊息直接播報，減少戰鬥中查看文字的頻率。

![聊天語音播報設定](images/09-chat-tts.png)

---

## 聲音來源

可以在三種聲音來源之間切換：

- **Microsoft SpeechSynthesizer**：使用 Windows 已安裝的系統音色，在本機合成，資源占用較低。
- **本機模型（Kokoro v1.1）**：使用隨應用程式分發的 Kokoro v1.1 INT8 模型，透過 sherpa-onnx 在本機執行，提供多種中英文音色。
- **GPT-SoVITS 角色語音**：連線到使用者已經啟動的 GPT-SoVITS API 服務，可為不同角色儲存模型、參考音訊與參考文字。應用程式本身不會安裝或啟動 GPT-SoVITS。

Kokoro 是內建模型，不需要在應用程式中下載、匯入或刪除。若模型檔案遺失，「模型狀態」會顯示提示，音色選擇也會自動停用。

## 播報設定與音訊輸出裝置

可以調整音色、語速與音量，並使用「試聽」確認播報效果。

在「音訊輸出裝置」中，可選擇**系統預設**（Windows 預設輸出），或指定喇叭、耳機與虛擬音效卡。連接或移除裝置後，按下**重新整理**以更新清單。如果已儲存的裝置顯示「目前無法使用」，請重新連接或改選其他可用裝置（包括系統預設輸出）。

## Kokoro 模型與執行緒數

選擇「本機模型（Kokoro v1.1）」後，可從「模型狀態」檢查內建模型是否可用。可透過「效能占用」將 Kokoro 執行緒數設為 **1～16**：執行緒越多，產生語音通常越快，但也可能占用更多 CPU 資源。建議先使用預設值。若模型遺失，請確認安裝內容完整，而非嘗試從程式內下載模型。

## GPT-SoVITS 連線與角色設定

1. 自行啟動 GPT-SoVITS API 服務，在「服務位址」填入 API 位址（預設 `http://127.0.0.1:9880`），再於「服務狀態」按下**檢查**以確認服務可連線。
2. 前往「角色設定」，選擇**新增角色**。角色名稱和參考音訊路徑為必填。GPT（`.ckpt`）與 SoVITS（`.pth`）模型權重路徑則可留空，表示使用 API 服務已載入的模型。
3. 視需要設定參考文字、參考語言與輸出語言。儲存後對要播報的角色選擇**使用**；也可**編輯**或**刪除**已儲存的角色。
4. 使用「試聽」檢查角色的效果。合成語音時，GPT-SoVITS 服務必須持續執行，且填入的檔案路徑須能由該 API 服務存取。

本程式只負責連線，不會自行安裝或啟動 GPT-SoVITS 服務。

## 訊息佇列

- **最大等待訊息數**決定最多保留多少則尚未播報的訊息。
- **訊息等待過久**可以設為永不過期，或依秒數捨棄已失去時效的舊訊息。
- 佇列已滿時會優先捨棄較舊的等待訊息。

友軍、敵軍與系統訊息可以分別控制。若啟用了[不文明內容過濾](zh-Hant-Content-Filter)中的 TTS 過濾，播報會套用對應策略。
