## 啟動行為

在 **執行設定** 中，可以選擇程式啟動時是否自動開啟 **懸浮視窗**及 **Dashboard**。若希望程式安靜地在背景執行，可將對應選項關閉，需要時再從系統匣開啟。

## 區域網路存取與 Windows 防火牆

WarThunderChatTranslator 的本機 HTTP 服務會監聽區域網路介面，**監聽本身不需要系統管理員權限**。手機、平板或另一台電腦是否能開啟 Dashboard，主要取決於 Windows 防火牆是否存在有效的允許規則。

如果你**只在這台電腦上使用 Dashboard**，不需要設定防火牆規則；因此顯示「尚未設定」本身並不是錯誤。

若要讓區域網路內其他裝置存取 Dashboard：

1. 開啟 **執行設定 → 區域網路存取**。
2. 查看 **Windows 防火牆**卡片的狀態。
3. 點選 **允許區域網路存取**。一般權限執行時，程式會先說明用途，再要求一次 Windows UAC 系統管理員確認。
4. 設定完成後，程式會優先選擇目前有流量並可連線到外部網路的網路介面，同時顯示 Dashboard 位址與 QR Code；手機或平板可直接掃描。
5. 如需限制其他區域網路裝置，可啟用 **存取驗證**。驗證預設關閉；啟用後使用每次程式啟動時隨機產生的工作階段令牌。本機存取永遠免驗證。

應用程式會優先判斷 Windows 防火牆是否**實際上已經允許目前程式接收目前 Dashboard 流量**。如果你已在 Windows 的「允許存取」提示中放行，或系統管理員／原則已建立足夠的輸入允許規則，應用程式會直接採用，不會要求重複「修復」。只有在確實沒有可用允許規則時，才會提示建立或修復。

應用程式自行建立的規則會限制為：**目前 WarThunderChatTranslator 程式完整路徑 + 目前 TCP 連接埠 + LocalSubnet + Private/Domain 網路設定檔**，並不是單純把某個連接埠開放給所有程式。

### 防火牆狀態說明

| 狀態 | 含義與處理 |
| --- | --- |
| **已允許區域網路存取** | Windows 目前已有能涵蓋此應用程式、目前 Dashboard TCP 連接埠與目前網路設定檔的有效輸入允許規則。它可以由應用程式、Windows「允許存取」提示或系統管理員建立；只要已經足夠，就不會要求修復。 |
| **尚未設定防火牆規則** | 沒有符合的規則。只在本機使用時可保持不設定；需要其他裝置存取時再啟用。 |
| **防火牆規則需要更新** | 已找到 WarThunderChatTranslator 規則，但程式路徑、連接埠或其他屬性不再相符。點選 **修復防火牆規則**。 |
| **本機 HTTP 服務未執行** | Dashboard 服務目前未成功啟動，請先重新啟動程式或檢查啟動錯誤。 |
| **無法檢查防火牆規則** | 無法讀取 Windows 防火牆狀態，可稍後重試或查看記錄檔。 |

### Microsoft Store 更新後的規則

Microsoft Store 更新後，版本化安裝路徑可能變更。舊規則即使名稱仍正確，也可能仍指向上一版 EXE，因此已無法視為有效規則。

程式會先按**實際有效範圍**檢查目前 EXE、TCP 連接埠、方向、Allow 狀態與目前網路設定檔。Windows 自動產生的較寬泛應用程式規則（例如目前程式的 Any protocol / Any port）只要確實涵蓋 Dashboard 流量，也會視為有效。對於應用程式自行管理的規則，仍會保留舊路徑判定，以便真正失效時提示修復：

- 一般權限啟動時，若偵測到舊規則，程式會顯示通知但不會在啟動時突然跳出 UAC；點選通知會直接開啟主視窗並跳到 **執行設定 → 區域網路存取**，再由你決定是否修復。
- 若程式已經以系統管理員權限執行，而且使用者沒有明確停用自動管理，程式可自動建立或修復規則。
- 只要既有規則正確，一般權限執行一樣可以接受區域網路連線，不需要長期以系統管理員身分執行。

### 移除規則

已設定規則時，可以點選 **移除防火牆規則**。一般權限執行時，只有在你主動點選移除後才會要求 UAC。

手動移除成功後，程式會記住這個選擇，下次即使以系統管理員權限啟動也不會自動重新建立。之後再次點選 **允許區域網路存取**，即可恢復規則與自動維護。

> 目前管理的區域網路規則只套用於 **Private / Domain** 網路設定檔與 **LocalSubnet**。若 Windows 將目前網路識別為 Public，其他裝置仍可能無法連線。

## 訊息更新頻率

**遊戲聊天更新間隔**與 **Dashboard 更新間隔**可分別調整。一般使用時保留預設值即可；希望顯示更即時可稍微縮短，若想降低檢查頻率則可以增加。

## 戰鬥結束後如何處理聊天紀錄？

| 選項 | 適合什麼情況 |
| --- | --- |
| **不清理** | 想繼續查看先前的聊天 |
| **邏輯清理** | 想讓新一場戰鬥的畫面更清爽，適合日常使用 |
| **物理清理** | 想更徹底地移除舊聊天；移除後無法從介面還原 |

也可以調整聊天快取容量。快取並不是永久聊天備份；若想盡量保留較早的內容，請避免使用會永久清除資料的選項。

## 網路與代理設定

進入 **代理設定**，根據網路狀況選擇：

- **不使用代理**：一般網路環境可以先選這項。
- **使用系統代理**：讓程式跟隨 Windows 的代理設定。
- **自訂代理**：只有在已有可用代理服務與連線資料時才使用。

變更後可回到 **翻譯設定 → 測試翻譯功能**，確認翻譯服務是否仍正常連線。

## 兩種常見使用方式

**遊戲內精簡模式：** 啟用「啟動時開啟懸浮視窗」，停用 Dashboard 自動開啟。

**第二螢幕 / 區域網路裝置模式：** 開啟 Dashboard，並僅在其他裝置需要存取時設定防火牆規則；若只在本機瀏覽器使用 Dashboard，則不需要區域網路防火牆規則。
